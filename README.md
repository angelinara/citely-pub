# Citely

[citely.uk](https://www.citely.uk) is a static site that provides **general references**
— not legal advice — on everyday consumer-law questions in **England & Wales**, with
every answer cited to primary legislation and official sources. No AI sits in the
user's path; content is written offline and human-reviewed before it ships.

## Disclaimer

Content may be out of date or may not apply to a reader's situation. Using the site
creates no solicitor–client relationship, and it is not affiliated with any court,
regulator, or government body. Readers needing advice should contact Citizens Advice
or a regulated solicitor.

## This repository

This repository holds the built site in `public/`, deployed to GitHub Pages on every
push to `master`, and the `open-pr` skill used to submit each build. The source and
authoring pipeline live in a separate, private repository.
